## Возможности

- **Кнопка копирования для форматированного текста** — встроенный код, жирный, курсив, подчёркнутый, зачёркнутый, выделенный, заголовки, теги, внутренние и внешние ссылки
- **Оба режима** — работает в режиме редактирования (исходник) и чтения (живой предпросмотр / предпросмотр) с единым списком переключателей
- **Единые настройки типов содержимого** — один список флажков для включения/отключения каждого типа; не нужно редактировать шаблоны или CSS-селекторы
- **Управление видимостью через команду** — включайте и выключайте кнопки командой **Переключить показ/скрытие кнопки копирования**
- **Пользовательский значок** — выберите значок кнопки копирования
- **Уведомление о копировании** — опциональное уведомление после копирования
- **Ноль зависимостей** — никаких внешних библиотек во время выполнения, только API Obsidian
- **Многоязычный интерфейс** — English, 中文, Русский

## Использование

1. Установите и включите плагин
2. В любой заметке кнопка копирования появляется справа от поддерживаемого содержимого (например, `встроенный код`, **жирный**, ==выделенный==, # Заголовок, #тег, [[ссылка]])
3. Нажмите кнопку, чтобы скопировать содержимое; скопированный текст соответствует типу (например, теги сохраняют префикс `#`)
4. Используйте команду **Переключить показ/скрытие кнопки копирования**, чтобы в любой момент показать или скрыть все кнопки копирования

Настройте, какие типы содержимого показывают кнопку, через **Настройки → Fast Copier**.

## Настройки

| Настройка | По умолчанию | Описание |
|-----------|-------------|----------|
| **Типы содержимого** | Все включены | Список флажков типов содержимого (встроенный код, жирный, курсив, подчёркнутый, зачёркнутый, выделенный, заголовок, тег, внутренняя ссылка, внешняя ссылка). Включённые типы показывают кнопку копирования. |
| **Значок кнопки копирования** | copy | Значок кнопки копирования. |
| **Показывать уведомление** | Вкл | Показывать уведомление после копирования в буфер обмена. |

> **Подсказка:** Показ или скрытие кнопок копирования управляется командой **Переключить показ/скрытие кнопки копирования**, а не настройкой.

> **Требования:** Obsidian 1.13.0 или новее.

## Установка

### Из сообщества плагинов Obsidian

1. Откройте **Настройки → Сторонние плагины**
2. Отключите **Безопасный режим**
3. Нажмите **Обзор** и найдите "Fast Copier"
4. Установите и включите

### Вручную

```bash
cd /path/to/vault/.obsidian/plugins
git clone https://github.com/TracingOrigins/obsidian-fast-copier-plugin.git fast-copier
cd fast-copier
npm install && npm run build
```

Затем включите плагин в **Настройки → Сторонние плагины**.

## Разработка

1. Скопируйте `.env.example` в `.env` и укажите `VAULT_PATH` — путь к вашему хранилищу Obsidian:
   ```
   VAULT_PATH=C:/Users/YourName/Documents/MyVault
   ```
2. Установите зависимости и начните разработку:

```bash
npm install        # установка зависимостей
npm run dev        # режим отслеживания (авто-деплой в хранилище)
npm run build      # production сборка (авто-деплой в хранилище)
npm run lint       # запуск eslint
```
